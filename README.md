# 必应网页与图片搜索（astrbot_plugin_bing_search）

一个独立的 AstrBot 插件：让 AI 在 `cn.bing.com` 上搜索公开网页、按需筛选时效并引用来源，
也可以单独搜索并转发 1-5 张相关图片。

> **网页搜索与图片转发是两项完全独立的能力。**普通网页搜索不会附带图片，也不会触发图片转发。

## 能力一览

| 能力 | 自然语言（主 Agent 工具） | 中文命令 | 英文兼容命令 |
| --- | --- | --- | --- |
| 网页搜索 | `web_search_bing` | `/bing搜索 <关键词>` | `/search`、`/bing_search` |
| 图片转发 | `image_search_bing` | `/bing搜图 <关键词>` | `/bing_image` |

- **网页搜索**：返回带标题、摘要与公开来源地址的结果，支持时效筛选（day/week/month/year）。
- **图片转发**：图片在**工具调用期间**由插件直接发送到当前对话；调用方只收到**不含图片直链**的
  文字回执（含成功 / 失败数量）。命令路径则通过消息链直接返回图片。

## 生命周期

```
网页请求 -> bing 网页搜索 -> 带来源的受限摘要 -> AI 组织回答
图片请求 -> bing 图片搜索 -> 插件直接发图到当前对话 -> AI 收到不含图片直链的回执
```

## 配置项（WebUI 可视化）

| 配置 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | `true` | 插件总开关；关闭后不发起搜索请求。 |
| `enable_web_search` | `true` | 单独控制网页工具与网页命令。 |
| `enable_image_search` | `true` | 单独控制搜图工具与搜图命令。 |
| `bing_host` | `cn.bing.com` | 地址来源 / Bing 搜索地址。 |
| `default_count` | `5` | 默认网页结果数，范围 1-50。 |
| `default_image_count` | `3` | 默认转发图片数，范围 1-5。 |
| `need_summary` | `true` | 是否请求搜索结果的摘要。 |
| `need_content` | `false` | 是否请求完整网页正文，建议保持关闭。**本版本仅保留配置项，默认不抓取正文。** |
| `need_url` | `true` | 是否要求带来源地址的结果。 |
| `timeout_seconds` | `30` | 单次请求超时，范围 5-120 秒。 |
| `max_snippet_chars` | `1200` | 每条结果进入 AI 上下文的最大字符数，范围 200-8000。 |

## 安装与兼容性

- **AstrBot**：`>=4.26.7`（`metadata.yaml` 中声明，仅设最低版本，不设 4.x 小版本上限）
- **平台**：`aiocqhttp`
- **Python 依赖**：仅使用 AstrBot 已内置的 `aiohttp`，无需额外安装。

将本插件目录放入 AstrBot 的 `data/plugins/` 下，重启或在 WebUI 中重载插件即可。

## 设计说明

- **来源可核对**：网页结果包含标题、摘要和公开来源地址。
- **上下文可控**：默认不请求完整网页正文，每条结果长度可通过 `max_snippet_chars` 独立限制。
- **图片直接发送**：图片在工具调用期间发到当前对话，不把图片直链交给 AI 重发。
- **失败不泄密**：日志与回执只记录稳定错误码（如 `E_TIMEOUT`、`E_NETWORK`），
  不回显 API Key 或远端错误正文。
- **健壮性**：某张图片发送失败时会继续尝试剩余图片，并在回执中准确报告成功与失败数量。

## 免责声明

- 图片来自公开网页，插件在结果中保留其来源页；转载、版权和使用范围由使用者自行判断。
- 本插件通过解析 `cn.bing.com` 的公开搜索结果页工作，结果内容与可用性依赖该站点；
  请遵守目标网站的服务条款与相关法律法规，合理控制请求频率。
